# Personal Finance Tracker

Aplicación web personal para registrar ingresos y gastos cotidianos —manuales o
recurrentes— y entenderlos mediante un dashboard, sin convertir el seguimiento
diario en otra tarea pesada.

El proyecto se encuentra en fase de definición. La documentación es, por ahora,

## Principios del producto

1. Privacidad y propiedad de los datos.
2. Registro manual en menos de 15 segundos.
3. Información trazable, no gráficos decorativos.
4. Un flujo sencillo para movimientos manuales y recurrencias mensuales.
5. Evolución progresiva sin anticipar cuentas, bancos o inversión.
